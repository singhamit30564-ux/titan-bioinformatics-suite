## Phase 2 — Layer A source (`titan_core/`) — status

Source-complete: mmap+rayon chunked FASTQ/FASTQ.GZ/BGZF parser (CRLF /
truncated / malformed tolerant, Phred+33/+64 autodetect, `qmin` sentinel fix
so Phred64 detection can fire), one-pass streaming QC (per-base qual, GC,
length hist, N, adapters, overrep k-mers, HLL/Bloom dup estimate), self-contained
BAM/SAM + VCF/BCF decoders (documented trade-off vs noodles/rust-htslib: no C
toolchain, no external htslib), region queries, coverage tracks, flagstat,
banded SW/NW affine Gotoh core (portable scalar, auto-vectorizable; AVX2 only
for ungapped seed extension) + k-mer seed-and-extend mapper, canonical 2-bit
k-mer counts. API surface `parse_fastq / qc_fastq / read_bam / parse_vcf /
align / kmer_count / CancelToken`; GIL released; progress callback marshalled
on the main thread; bytes-in/bytes-out. Criterion benches + proptest fuzz.

**Honest status:** `cargo`/`rustc` are not installed in this sandbox (install
attempt failed, no root) — the crate is **not compiled here**. Two remaining
defects found in review are fixed in source (CRLF test used nonexistent
`Vec<u8>::replace` → byte-wise loop; `parse_payload` merged `qmin` started at
0 → `u8::MAX` sentinel). CI runs `cargo fmt/clippy/test --no-default-features`
+ `maturin build`; those results are `not measured` locally.

## Phase 4 — Layer B (`titan_stats/` + `r/`)

DE via PyDESeq2 default → R bridge (`Rscript r/de_runner.R`, JSON in/out,
explicitly **not** rpy2; DESeq2/edgeR/limma-voom; low-count filter, batch
covariate) → Welch t-test fallback (labelled `fallback-ttest` in method +
results). Shared schema: `results / normalized_counts / size_factors /
dispersion / n_genes_* / contrast / warnings / provenance`. Plot-ready JSON:
volcano, MA, PCA, sample-distance, clustered top-N heatmap, GO/KEGG lists.
Variant ML: xgboost → sklearn → NumPy GNB, fixed seeds, stratified CV, ROC/PR,
calibration, model card, optional SHAP; synthetic data carries the literal
`SYNTHETIC:` prefix and `SYNTHETIC` markers in code, UI and exports. Dimred:
PCA-SVD, UMAP→PCA fallback (labelled), k-means, hierarchical, cluster metrics.
Per-run provenance (input SHA-256, package versions, params, seed) feeds
privacy.py/ELN. Pages 98/99/100 follow page conventions; every button verified
via `streamlit.testing` (no `st.error` on the happy path).

## Phase 9 — Migration notes · limitations · next steps

### Migration notes
1. Install: `pip install -r requirements.txt` (core) then optionally
   `requirements-optional.txt`. Build the Rust wheel with
   `maturin develop --release -m titan_core/Cargo.toml` (or use the CI wheel
   artifact). Until then `titan_utils.engine` reports `active=python` — same
   schemas, slower on large FASTQ/BAM/VCF.
2. API: `/api/run` is unchanged (v1 clients keep working). v2 consumers use
   `/api/v2/*`; regenerate types with `scripts/export_openapi.py` +
   `npm run openapi:types` after changing `api_v2.py`.
3. Registry IDs 261–265 are append-only. Console pages for 261–264 point at
   `98_Differential_Expression.py`, 265 at `99_Variant_ML.py`.
4. Pages 20/27/28/75/77 behave identically; the only visible addition is an
   engine badge caption. QUAL formatting in page 27 preserves the legacy
   integer-style text ("50" not "50.0").
5. `r/` lives at the repo root (not `titan_stats/r/`); `r_bridge.py` resolves
   it relative to the repository.

### Limitations (measured vs not measured)
* Rust crate compiled: **not measured** locally (no toolchain); CI validates.
* R bridge execution: **not measured** locally (no `Rscript`); the
  `RBridgeError` absence path is unit-tested.
* Playwright e2e: **not measured** locally (browser download blocked); specs +
  CI step are in place.
* Benchmark throughput table: **not measured** — the harness refuses to emit
  estimated numbers; run `scripts/run_benchmarks.sh` on target hardware.
* igv.js genome browser: optional dependency; panel reports unavailability.
* MongoDB job history: unimplemented by design (OFF by default; metadata-only
  hook documented) — job history is in-RAM and resets with the API process.

### Next steps
1. Run `cargo fmt && cargo clippy --no-default-features -- -D warnings &&
   cargo test --no-default-features` and `maturin build` on a Rust host; fix
   any compiler nits and publish the wheel as a CI artifact.
2. Run `Rscript r/run_tests.R` in the devcontainer image (R 4.4 + testthat).
3. Run `scripts/run_benchmarks.sh` at 1M/10M/50M reads and commit the
   `docs/benchmarks-*.md` (all cells MEASURED).
4. `npx playwright install --with-deps chromium && npx playwright test` in CI
   (first run may need small selector tweaks).
5. Optional: MongoDB metadata store behind `TITAN_JOB_STORE=mongodb`
   (metadata only), and `npm install igv@3.2.0` for the embedded browser.
