# 📱 Titan Bio — Android Wrapper (APK-ready, beta)

## What this actually is (read this first — honesty first)

This folder is a **minimal Capacitor WebView shell**, not a native rewrite of
the Titan Bioinformatics Suite. Concretely:

* It is a thin Android app whose single screen is a WebView pointed at your
  **deployed, live** Titan Bioinformatics Suite URL (set in
  `capacitor.config.json` → `server.url`).
* Titan Bioinformatics Suite is a Streamlit server app — it is not a static
  site — so this wrapper cannot bundle the whole app offline inside the APK.
  It needs the same internet connection the website itself needs.
* `www/index.html` is just a one-second fallback splash shown before the
  WebView navigates to your live URL (or if the device truly has no network).
* Any offline behavior comes from the **PWA layer already built into the
  web app** (`static/manifest.json`, `static/sw.js` — see Feature 2 of this
  pack) running *inside* this WebView, not from anything wrapper-specific.
* This is a **beta / DIY** wrapper: nobody has published it to the Play
  Store on your behalf, no signing keys are included, and no CI builds an
  APK automatically. You build it yourself, locally, following the steps
  below.

If you want a fully offline, 100% native Android app, that is a much larger
rewrite outside the scope of this feature pack — this wrapper's honest job is
"turn the existing website into an installable icon on an Android home
screen," nothing more.

## Prerequisites

* [Node.js](https://nodejs.org/) 18+ and npm
* [Android Studio](https://developer.android.com/studio) (for the Android
  SDK, emulator, and to actually build/sign the APK)
* Your Titan Bioinformatics Suite already deployed somewhere reachable over
  HTTPS (Streamlit Community Cloud, your own server, etc.) — grab that URL
  before step 1.

## 5-step build

1. **Install dependencies** (from inside this `android-wrapper/` folder):
   ```bash
   cd android-wrapper
   npm install
   ```
2. **Add the Android platform**:
   ```bash
   npx cap add android
   ```
   This generates a standard `android/` Gradle project next to this folder.
3. **Point the wrapper at your deployed app**, then sync:
   - Edit `capacitor.config.json` and replace
     `"https://REPLACE-WITH-YOUR-DEPLOYED-TITAN-BIO-URL"` with your real
     HTTPS URL.
   - Run:
     ```bash
     npx cap sync
     ```
4. **Open the project in Android Studio**:
   ```bash
   npx cap open android
   ```
   Let Gradle finish syncing the first time you open it (can take a few
   minutes).
5. **Build the APK**: in Android Studio, use
   `Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)`. The signed/unsigned APK
   appears under `android/app/build/outputs/apk/`. Install it on a device
   with `adb install app-debug.apk`, or sideload it directly.

## Splash screen

The splash config in `capacitor.config.json` uses the suite's dark/gold
brand: background `#0a0e17` with a gold (`#d4af37`) spinner, matching the
"TITAN BIO" wordmark used in `static/icons/icon.svg`. Replace
`android/app/src/main/res/drawable*/splash.png` (generated by
`cap add android`) with your own exported art if you want a custom splash
image instead of the plain color background.

## v3.5 update — the `web/` dashboard is the PWA

The React+TS dashboard in `web/` now ships its own PWA layer
(`web/public/manifest.webmanifest`, `web/public/sw.js` — API traffic is never
cached, honoring Zero Data Retention). To wrap THAT app in this Capacitor
shell instead of the classic Streamlit site, point `server.url` at your
deployed Express gateway (`web/server/index.js`, default port 4173) and set
`webDir` to `../web/dist` (the built dashboard bundle). The wrapper still
needs network access to the API backend; sequences are processed in server
RAM only (ZDR) regardless of client.
